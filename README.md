# 🌸 Antasari Mart

**Antasari Mart** adalah platform *e-commerce* dan *marketplace* kampus modern yang dikhususkan untuk sivitas akademika UIN Antasari (Banjarmasin & Banjarbaru). Platform ini menghubungkan pembeli mahasiswa, tenant/koperasi, kurir (driver), hingga pengelola utama sistem.

---

## 🚀 Fitur Unggulan

1. **👑 Super Admin Control Center**: Dashboard eksklusif pemilik platform untuk memantau statistik total pengguna, omset platform secara real-time, grafik aktivitas transaksi, kotak masuk kritik & saran, serta manajemen status akun PRO.
2. **💎 Antasari Mart PRO**: Sistem berlangganan bulanan (mulai dari Rp10rb/bln) dengan keuntungan eksklusif untuk 4 peran:
   - **Pembeli**: Bebas ongkir & diskon khusus.
   - **Penjual**: Top ranking di katalog & 0% fee penjualan.
   - **Driver**: Prioritas penerimaan order & bonus pengantaran.
   - **Admin Koperasi**: Manajemen inventaris dan broadcast promo instan.
3. **💬 Real-Time Chat & Web Push Notifications**: Fitur perpesanan instan antar pengguna lintas role, dilengkapi notifikasi pop-up browser (Chrome) otomatis di pojok kanan bawah.
4. **🧩 Aesthetic Flower Bouquet Captcha**: Sistem verifikasi keamanan geser puzzle (*slider captcha*) menggunakan latar belakang foto buket bunga estetik untuk mencegah serangan bot.
5. **👤 10 Pilihan Avatar Kartun & Upload Galeri**: Kustomisasi profil interaktif dengan karakter senyum ceria/elegan.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React, Vite, TypeScript, CSS Custom Properties.
- **Backend**: Node.js, Express.js.
- **Database**: PostgreSQL.
- **Keamanan & Notifikasi**: JWT Auth, Browser Notifications API, SweetAlert2.
